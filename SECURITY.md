# Security Policy

> **Note**: This is a fork of [rumenx/php-seo](https://github.com/RumenDamyanov/php-seo) modified for Intent Framework.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

**DO NOT** create a public GitHub issue for security vulnerabilities.

Please email: **aamirabdullah33@gmail.com**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### What to Expect

- **Acknowledgment**: Within 48 hours
- **Assessment**: Within 7 days
- **Fix**: Within 30 days if confirmed

## Security Best Practices

### API Key Management

- Never commit API keys to version control
- Use environment variables
- Rotate keys regularly

### Content Validation

- Validate and sanitize all user inputs
- Review AI-generated content before display

### Framework Integration

- Keep Intent Framework and dependencies updated
- Use framework security features (CSRF, etc.)
